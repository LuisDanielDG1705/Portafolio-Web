# Configuración del Portafolio

Este es un sitio estático creado con la plantilla Aerial y contenido personalizado.

## Archivos importantes
- `index.html`: página principal del portafolio.
- `assets/css/main.css`: estilos base de la plantilla.
- `assets/css/portfolio.css`: estilos adicionales y personalizados.
- `assets/images/`: imágenes usadas en el portafolio.
- `assets/images/projects/.gitkeep`: marcador de carpeta para proyectos.

## Cómo ver el sitio
1. Abre `index.html` directamente en el navegador.
2. Si usas VS Code, instala una extensión como Live Server y abre el proyecto desde allí.

## Qué editar
- `index.html`: cambia los textos entre corchetes (`[TU_NOMBRE]`, `[TU_EMAIL]`, etc.).
- `assets/css/portfolio.css`: ajusta colores, fuentes y diseño adicional.
- `assets/images/projects/`: reemplaza las imágenes placeholder por capturas reales de tus proyectos.

## Notas
- El sitio no requiere compilación ni dependencias adicionales.
- Si quieres usar GitHub Pages, sube el contenido del directorio `Portafolio` al repositorio y configura la rama de publicación.
